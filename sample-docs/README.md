# Sample documents

Upload these through the Documents tab during the workshop to follow along with the demos referenced in the slides — no need to bring your own files.

- `paid-time-off-policy.pdf` — used in the evaluation dataset demo ("How many PTO days per year?" → 21 days).
- `information-security-policy.pdf` — used in the evaluation dataset demo ("MFA requirements?" → mandatory where supported).
- `expense-reimbursement-policy.pdf` — the **current (2026)** expense policy: over $5,000 requires VP + Finance approval. Used in the evaluation dataset demo and as the "this year" document in the scoped-vs-unscoped demo.
- `2025-expenses.pdf` — the **superseded (2025)** expense policy: over $3,000 requires VP + Finance approval. Upload this alongside `expense-reimbursement-policy.pdf` to reproduce the scoped-vs-unscoped conflict: ask "what's the approval threshold for expenses?" unscoped (may blend both years) vs. scoped to just `2025-expenses.pdf` (answers only from that file).

All four are fictional Acme Corporation policy documents generated for this workshop — safe to upload, no real company or personal data.
